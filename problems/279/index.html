Q279 完全平方数

完全背包求最少平方数个数

02

题目描述

先把输入、输出和限制读明白

给你一个整数 n ，返回 和为 n 的完全平方数的最少数量 。

完全平方数 是一个整数，其值等于另一个整数的平方；换句话说，其值等于一个整数自乘的积。例如，1、4、9 和 16 都是完全平方数，而 3 和 11 不是。

 

示例 1：

输入：n = 12
输出：3
解释：12 = 4 + 4 + 4

示例 2：

输入：n = 13
输出：2
解释：13 = 4 + 9
 

提示：

  • 1 <= n <= 104
03

分步讲解

把“会做”拆成可执行的思考步骤

为什么用 动态规划

把大问题写成状态，并让每个状态只算一次。

复杂度

复杂度：时间 O(n·sqrt(n))，空间 O(n)

  1. 01视角：这是「物品为 1,4,9,... 且可无限重复」的完全背包，求恰好装满的最少个数。
  2. 02转移：dp[i] = 1 + min(dp[i - j*j])，j*j <= i。
  3. 03数学解：拉格朗日四平方定理 -> 答案只可能是 1/2/3/4；
  4. 04当 n = 4^a·(8b+7) 时答案为 4（这个判定的 O(log n) 解法常被当作加分项）。
04

C++17 实现

保持 LeetCode 可直接提交的 Solution 写法

namespace lc0279 {
class Solution {
 public:
  int numSquares(int n) {
    vector<int> dp(n + 1, INT_MAX / 2);  // 除以 2 防止后面 +1 溢出
    dp[0] = 0;
    for (int i = 1; i <= n; ++i)
      for (int j = 1; j * j <= i; ++j) dp[i] = min(dp[i], dp[i - j * j] + 1);
    return dp[n];
  }
};
}
