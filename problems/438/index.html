题目描述

先把输入、输出和限制读明白

给定两个字符串 s 和 p，找到 s 中所有 p 的 异位词 的子串，返回这些子串的起始索引。不考虑答案输出的顺序。

 

示例 1:

输入: s = "cbaebabacd", p = "abc"
输出: [0,6]
解释:
起始索引等于 0 的子串是 "cba", 它是 "abc" 的异位词。
起始索引等于 6 的子串是 "bac", 它是 "abc" 的异位词。

 示例 2:

输入: s = "abab", p = "ab"
输出: [0,1,2]
解释:
起始索引等于 0 的子串是 "ab", 它是 "ab" 的异位词。
起始索引等于 1 的子串是 "ba", 它是 "ab" 的异位词。
起始索引等于 2 的子串是 "ab", 它是 "ab" 的异位词。

 

提示:

  • 1 <= s.length, p.length <= 3 * 104
  • s 和 p 仅包含小写字母
03

分步讲解

把“会做”拆成可执行的思考步骤

为什么用 滑动窗口

维护一个始终满足约束的连续区间，避免重复计算。

复杂度

复杂度：时间 O(26·n)，空间 O(1)

  1. 01思路：定长窗口（长度 = p.size()）。每步右进一个、左出一个，
  2. 02维护 26 计数数组，和 need 比较即可。
  3. 03窗口长度固定，所以用「进一个出一个」而不是 while 收缩。
  4. 04优化：用 diff 计数「还有几个字母数量不对」可做 O(n)，思路同 Q76。

C++17 实现

保持 LeetCode 可直接提交的 Solution 写法

namespace lc0438 {
class Solution {
 public:
  vector<int> findAnagrams(string s, string p) {
    vector<int> ans;
    const int n = (int)s.size(), m = (int)p.size();
    if (n < m) return ans;
    vector<int> need(26, 0), win(26, 0);
    for (char c : p) ++need[c - 'a'];
    for (int i = 0; i < n; ++i) {
      ++win[s[i] - 'a'];          // 右边进
      if (i >= m) --win[s[i - m] - 'a'];  // 左边出，维持定长
      if (i >= m - 1 && win == need) ans.push_back(i - m + 1);
    }
    return ans;
  }
};
}
