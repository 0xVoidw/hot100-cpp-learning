Q226 翻转二叉树

Easy
分类 二叉树 · 难度 Easy · 原题 invert-binary-tree

题目描述

给你一棵二叉树的根节点 root ，翻转这棵二叉树，并返回其根节点。

示例 1：

输入：root = [4,2,7,1,3,6,9]
输出：[4,7,2,9,6,3,1]

示例 2：

输入：root = [2,1,3]
输出：[2,3,1]

示例 3：

输入：root = []
输出：[]

提示：

  • 树中节点数目范围在 [0, 100] 内
  • -100 <= Node.val <= 100
💡 核心套路：递归交换左右孩子

讲解与思路

思路：每个结点交换左右孩子，递归下去。前序或后序都行（不像 Q101 需要成对比较）。

复杂度：时间 O(n)，空间 O(h)

/

带注释代码

namespace lc0226 {
class Solution {
 public:
  TreeNode* invertTree(TreeNode* root) {
    if (!root) return nullptr;
    std::swap(root->left, root->right);
    invertTree(root->left);
    invertTree(root->right);
    return root;
  }
};
}
