Q239 滑动窗口最大值

Hard
分类 子串/前缀和 · 难度 Hard · 原题 sliding-window-maximum

题目描述

给你一个整数数组 nums，有一个大小为 k 的滑动窗口从数组的最左侧移动到数组的最右侧。你只可以看到在滑动窗口内的 k 个数字。滑动窗口每次只向右移动一位。

返回 滑动窗口中的最大值 。

示例 1：

输入：nums = [1,3,-1,-3,5,3,6,7], k = 3
输出：[3,3,5,5,6,7]
解释：
滑动窗口的位置                最大值
---------------               -----
[1  3  -1] -3  5  3  6  7       3
 1 [3  -1  -3] 5  3  6  7       3
 1  3 [-1  -3  5] 3  6  7       5
 1  3  -1 [-3  5  3] 6  7       5
 1  3  -1  -3 [5  3  6] 7       6
 1  3  -1  -3  5 [3  6  7]      7

示例 2：

输入：nums = [1], k = 1
输出：[1]

提示：

  • 1 <= nums.length <= 105
  • -104 <= nums[i] <= 104
  • 1 <= k <= nums.length
💡 核心套路：单调递减双端队列，队头即窗口最大值

讲解与思路

思路：单调递减双端队列，存「下标」。

- 新元素进来前，把队尾所有 <= 它的弹出（它们再也不可能当答案了）

- 队首下标滑出窗口左边界就 pop_front

- 每个元素最多入队出队各一次 -> 总 O(n)

复杂度：时间 O(n)，空间 O(k)

带注释代码

namespace lc0239 {
class Solution {
 public:
  vector<int> maxSlidingWindow(vector<int>& nums, int k) {
    deque<int> dq;  // 下标，对应值单调递减
    vector<int> ans;
    for (int i = 0; i < (int)nums.size(); ++i) {
      while (!dq.empty() && dq.front() <= i - k) dq.pop_front();  // 过期
      while (!dq.empty() && nums[dq.back()] <= nums[i]) dq.pop_back();  // 淘汰劣势
      dq.push_back(i);
      if (i >= k - 1) ans.push_back(nums[dq.front()]);
    }
    return ans;
  }
};
}

测试用例（本仓库，与代码一一对应）

lc0239::Solution s;
  vector<int> a{1, 3, -1, -3, 5, 3, 6, 7};
  CHECK_EQ(s.maxSlidingWindow(a, 3), vector<int>{3, 3, 5, 5, 6, 7});
  vector<int> b{1};
  CHECK_EQ(s.maxSlidingWindow(b, 1), vector<int>{1});
  vector<int> c{9, 8, 7, 6, 5};  // 严格递减 → 每步都不会淘汰队尾，但「过期弹出」把队长压在 ≤ k
  CHECK_EQ(s.maxSlidingWindow(c, 3), vector<int>{9, 8, 7});
  vector<int> d{1, 1, 1};
  CHECK_EQ(s.maxSlidingWindow(d, 2), vector<int>{1, 1});
