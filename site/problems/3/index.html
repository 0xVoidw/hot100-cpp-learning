题目描述

先把输入、输出和限制读明白

给定一个字符串 s ，请你找出其中不含有重复字符的 最长 子串 的长度。

 

示例 1:

输入: s = "abcabcbb"
输出: 3
解释: 因为无重复字符的最长子串是 "abc"，所以其长度为 3。注意 "bca" 和 "cab" 也是正确答案。

示例 2:

输入: s = "bbbbb"
输出: 1
解释: 因为无重复字符的最长子串是 "b"，所以其长度为 1。

示例 3:

输入: s = "pwwkew"
输出: 3
解释: 因为无重复字符的最长子串是 "wke"，所以其长度为 3。
     请注意，你的答案必须是 子串 的长度，"pwke" 是一个子序列，不是子串。

 

提示：

  • 0 <= s.length <= 105
  • s 由英文字母、数字、符号和空格组成
03

分步讲解

把“会做”拆成可执行的思考步骤

为什么用 滑动窗口

维护一个始终满足约束的连续区间，避免重复计算。

复杂度

复杂度：时间 O(n)，空间 O(字符集) —— 这里按 256 个字节取值开定长数组。

  1. 01思路：last[c] 记录字符 c 上次出现的下标。遇到重复时不必一步步缩左边界，
  2. 02直接把 l 跳到 last[c]+1（前提 last[c] >= l，否则会倒退）。
  3. 03这就是「带跳转的滑动窗口」，比逐步收缩更快也更短。
  4. 04写成 last[128] 的话，一旦数据里有 ≥128 的字节（比如 UTF-8 中文）就是栈越界，
  5. 05而编译器与用例都不一定报得出来。

滑动窗口 [L,R)：右指针扩；遇到重复就把 L 跳到重复字符后面。窗口内始终无重复，长度取最大。

C++17 实现

保持 LeetCode 可直接提交的 Solution 写法

namespace lc0003 {
class Solution {
 public:
  int lengthOfLongestSubstring(string s) {
    int last[256];  // 必须覆盖 unsigned char 的全部值域 [0,255]
    std::fill(std::begin(last), std::end(last), -1);
    int ans = 0, l = 0;
    for (int r = 0; r < (int)s.size(); ++r) {
      int c = (unsigned char)s[r];
      if (last[c] >= l) l = last[c] + 1;  // 只有重复点在窗口内才收缩
      last[c] = r;
      ans = max(ans, r - l + 1);
    }
    return ans;
  }
};
}
