02

题目描述

先把输入、输出和限制读明白

给定一个 n × n 的二维矩阵 matrix 表示一个图像。请你将图像顺时针旋转 90 度。

你必须在 原地 旋转图像，这意味着你需要直接修改输入的二维矩阵。请不要 使用另一个矩阵来旋转图像。

 

示例 1：

输入：matrix = [[1,2,3],[4,5,6],[7,8,9]]
输出：[[7,4,1],[8,5,2],[9,6,3]]

示例 2：

输入：matrix = [[5,1,9,11],[2,4,8,10],[13,3,6,7],[15,14,12,16]]
输出：[[15,13,2,5],[14,3,4,1],[12,6,8,9],[16,7,10,11]]

 

提示：

  • n == matrix.length == matrix[i].length
  • 1 <= n <= 20
  • -1000 <= matrix[i][j] <= 1000

 

03

分步讲解

把“会做”拆成可执行的思考步骤

为什么用 矩阵

把二维坐标关系转成有边界的行列遍历或原地标记。

复杂度

复杂度：时间 O(n^2)，空间 O(1)

  1. 01思路：顺时针 90° = 先沿主对角线转置，再把每一行左右翻转。
  2. 02（逆时针 90° = 转置 + 上下翻转整个矩阵，或先左右翻转再转置）
  3. 03推导：转置后 matrix[i][j] = 原[j][i]；再行翻转 -> 位置 (i, n-1-j) = 原[j][i]，
  4. 04即新[i][n-1-j] = 原[j][i]，正是顺时针 90° 的定义。

C++17 实现

保持 LeetCode 可直接提交的 Solution 写法

namespace lc0048 {
class Solution {
 public:
  void rotate(vector<vector<int>>& m) {
    const int n = (int)m.size();
    for (int i = 0; i < n; ++i)
      for (int j = i + 1; j < n; ++j)  // j 从 i+1 起，避免交换两次
        std::swap(m[i][j], m[j][i]);
    for (auto& row : m) reverse(row.begin(), row.end());
  }
};
}
