02

题目描述

先把输入、输出和限制读明白

给你一个二叉树的根节点 root ，判断其是否是一个有效的二叉搜索树。

有效 二叉搜索树定义如下：

  • 节点的左子树只包含 严格小于 当前节点的数。
  • 节点的右子树只包含 严格大于 当前节点的数。
  • 所有左子树和右子树自身必须也是二叉搜索树。

 

示例 1：

输入：root = [2,1,3]
输出：true

示例 2：

输入：root = [5,1,4,null,null,3,6]
输出：false
解释：根节点的值是 5 ，但是右子节点的值是 4 。

 

提示：

  • 树中节点数目范围在[1, 104] 内
  • -231 <= Node.val <= 231 - 1
03

分步讲解

把“会做”拆成可执行的思考步骤

为什么用 二叉树

每个节点都问同一个递归问题，再把左右子树答案合并。

复杂度

复杂度：时间 O(n)，空间 O(h)

  1. 01思路：自顶向下传递开区间 (lo, hi)。走左分支收紧上界为父值，走右分支收紧下界。
  2. 02真正的反例是 [10,5,15,nullopt,nullopt,6,20]：每个结点都比左孩子大、比右孩子小，
  3. 03但 6 落在 10 的右子树里，就必须 > 10 —— 只有「自上而下传区间」能拒掉它。
  4. 04（官方给的另一例 [5,1,4,nullopt,nullopt,3,6] 反而简单 —— 4 是 5 的右孩子却比 5 小，
  5. 05「只比父子」一眼就能拒掉，所以它并不能暴露这个 bug）
  6. 06用 long long 是因为边界要能表示 INT_MIN-1 / INT_MAX+1。
容易漏掉的点

致命错误：只比较「结点与左右孩子」—— 那只能保证局部有序。

C++17 实现

namespace lc0098 {
class Solution {
 public:
  bool isValidBST(TreeNode* root) { return valid(root, LLONG_MIN, LLONG_MAX); }

 private:
  static bool valid(TreeNode* n, long long lo, long long hi) {
    if (!n) return true;
    if (n->val <= lo || n->val >= hi) return false;  // 严格小于/大于
    return valid(n->left, lo, n->val) && valid(n->right, n->val, hi);
  }
};
}
